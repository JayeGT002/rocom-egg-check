# 精灵蛋范围查询系统 · UI 稿

## 交互

- 档位用 1–10 档离散双滑块选择区间；标题行右侧显示当前范围和重置按钮，重置回 1–10 档；双击范围指示器可直接输入档位（如 `2`）或范围（如 `2-3`），回车或失焦应用，Esc 取消；默认 1–10 档代表不过滤。
- 蛋组按钮按数据顺序三列排列（当前为 14 个），使用 Roco 的 paper 实心样式；选中后使用对应蛋组色，不限制选择数量，多选按任一匹配。名称统一使用“飞龙组”。当前导入数据中没有“无法孵蛋”蛋组的记录。标题右侧的文字按钮可重置蛋组筛选，不单独显示已选组标签、数量或上限提示。
- 新增属性筛选，18 种属性按钮带属性图标并按属性色显示，可自由多选，匹配任一选中属性。按钮自动换行，不固定每行列数；标题右侧可重置属性条件。筛选只检查每条进化链最低阶段的精灵属性，因此后续进化阶段的属性不会让该链命中。结果卡片在精灵名称下方显示第一形态的属性图标标签，样式参照 Roco 的浅色底、同色描边与文字。
- 纯数字搜索按三位图鉴编号精确匹配，例如 `12` 会规范成 `012`；文字则按精灵名包含匹配。
- 蛋重反查输入千克数值（保留三位小数），只保留蛋重区间包含该数值的初始形态；结果卡片在蛋重轨道上用竖线标出查询重量的位置。
- 结果卡片右上角档位块左侧的心形按钮可收藏或取消收藏精灵；存在收藏时，搜索框下方显示“只看收藏”开关及数量，收藏保存在本机浏览器存储，不随设置页的 JSON 导入导出迁移，加载数据时会移除已不存在的收藏。
- 结果区右上角可切换排序：默认顺序、图鉴编号、名称、档位从低到高/从高到低、蛋重区间从窄到宽/从宽到窄。
- 最近 5 条有效查询条件记录在侧栏“最近查询”中；文本输入在失焦后记录，持续聚焦期间不写入中间值，其他筛选变化稍后自动记录；点击记录可恢复全部筛选条件，也可清空。
- 每条进化链只显示最早阶段的形态，避免查询结果重复列出完整进化链；结果使用彼此留有间距的精灵卡片展示。
- 卡片显示的是每只精灵记录中的 `egg_weight`（精灵蛋重量范围，单位克，界面换算为千克），不是精灵本身体重。蛋组是独立字段。卡片使用不可拖动的静态区间轨道：轨道左右端点表示该精灵蛋重的最小值与最大值，暖色段表示迷你蛋区间，蓝色段表示巨大蛋区间，细刻线标出两个区间边界。每条轨道按该精灵自身的蛋重范围做线性映射，便于看出迷你蛋与巨大蛋在其总区间中的位置；巨大蛋数值右对齐。
- 卡片右上角档位为正方形色块，档位从 1 到 10 使用由浅到深的颜色，档位和描述文字均居中。
- 没有筛选条件时显示占位图；筛选后即时显示结果。

## 技术与许可

页面使用 `rocokingdom-ui` 的 `RocoTheme`、`Input`、`Button`，并加载组件库样式、字体及默认 paper / stone / primary 配色。自定义 CSS 控制布局、间距、结果卡片和静态蛋重可视化。

数据读取自独立的 `../data/pets.json`，每条精灵记录包含归一化后的属性值。属性数据按图鉴编号与名称匹配 Rocom Wiki Data 发布的 Wiki 图鉴数据；当前数据集对 Wiki 衍生数据采用 CC BY-SA 4.0。直接取自 Wiki 的资料应按对应页面声明记录来源。蛋组色、属性色和属性图标沿用 Rocom-Shiny-Helper；颜色与图标来源采用 MIT 许可。来源和许可范围见 `../DATA-LICENSES.md` 与 `THIRD-PARTY-NOTICES.md`。

组件库 npm 元数据声明 MIT 许可；正式发行时应保留对应 MIT 许可与版权声明。
